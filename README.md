# MANI Magic — нативное приложение для RuStore

Android-обёртка (Capacitor) вокруг веб-приложения `../app`, с нативным биллингом
RuStore Pay SDK — TWA/PWA-обёртки RuStore не пропускает, поэтому здесь настоящий
Android-проект. Собирается в облаке через GitHub Actions — локально Android
Studio/JDK не нужны.

## Статус

Репозиторий создан, CI полностью рабочий: подписанный `.aab` собирается зелёным
(`github.com/ugadaynet-prog/mani-magic-rustore`, workflow `build-rustore.yml`).
Ключ подписи сгенерирован и сохранён (см. шаг 2). Единственное, чего не хватает —
реальных значений из консоли RuStore (шаг 4) вместо плейсхолдеров.

## Что где

- `www/` — веб-приложение, копия `../app` (генерируется `node sync-www.js`, в git
  не попадает — не редактировать руками, менять только `../app`).
- `android/` — нативный проект. Ключевые файлы:
  - `app/src/main/java/app/manimagic/rustore/RuStoreBillingPlugin.kt` — мост
    JS ↔ RuStore Pay SDK (методы `purchaseProduct`, `getProducts`, `getPurchases`).
  - `app/src/main/java/app/manimagic/rustore/MainActivity.kt` — регистрирует плагин,
    обрабатывает возврат из банковского приложения при оплате.
  - `app/src/main/AndroidManifest.xml` — `console_app_id_value` (id из консоли
    RuStore, сейчас плейсхолдер) и схема для колбэка оплаты.
- `.github/workflows/generate-keystore.yml` — запустить один раз, создаёт ключ
  подписи приложения.
- `.github/workflows/build-rustore.yml` — собирает подписанный `.aab` при каждом
  пуше (или вручную).
- Сервер (`../server/src/rustore.js`, `../server/src/routes/rustore.js`) — проверяет
  покупку через Public API RuStore перед выдачей подписки (клиенту не верим на слово,
  тот же принцип, что и с вебхуком ЮKassa).

## Что нужно сделать (по шагам)

### 1. ~~Завести GitHub-репозиторий~~ ГОТОВО
`github.com/ugadaynet-prog/mani-magic-rustore`.

### 2. ~~Сгенерировать ключ подписи~~ ГОТОВО
Уже сгенерирован, секреты сборки (шаг 3) уже прописаны в репозитории. Сам файл
ключа сохранён локально в `../rustore-signing-key-DO-NOT-LOSE/` — **обязательно
сделать собственный бэкап** (облако/менеджер паролей): без него нельзя будет
выпускать обновления приложения, только публиковать заново как новое (для
пользователей — как переустановка).

### 3. ~~Секреты репозитория~~ ГОТОВО
`ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_PASSWORD`,
`ANDROID_KEY_ALIAS` — уже в Settings → Secrets репозитория.

### 4. Зарегистрировать приложение в консоли RuStore ← ТЕКУЩИЙ ШАГ
[RuStore Console](https://console.rustore.ru) → приложение с package name
**`app.manimagic.rustore`**.

**Товары** (Монетизация → раздел товаров) — id должны **точно совпадать** с
тарифами: `full_month`, `full_year`, `pro_month`, `pro_year` (цены как на сайте:
199/990/399/2490 ₽). Тип — потребляемый товар (не RuStore-подписка: у нас нет
автопродления, пользователь просто покупает ещё раз после истечения срока).

**Console App ID** — цифры в URL страницы приложения (`console.rustore.ru/apps/`**`111111`**`/...`)
— вписать в `android/app/src/main/res/values/strings.xml` вместо
`REPLACE_WITH_RUSTORE_CONSOLE_APP_ID`.

**API-ключ для сервера** (это НЕ простой токен, а пара RSA-ключей):
- Вкладка **«Компания»** (юрлицо) или **«Разработчик»** (физлицо/ИП) в шапке консоли.
- Слева — **API RuStore** → **Создать ключ**.
- Укажите название, выберите это приложение (или «Все приложения»), выберите
  методы: как минимум методы группы «Платежи и покупки» (нужна проверка счетов
  по invoiceId — метод «Получение данных платежа по идентификатору (v2)»).
- **Сгенерировать ключ** — приватный ключ покажется ОДИН раз, скопировать сразу.
- Пришлите мне **keyId** и сам **приватный ключ** — впишу в `.env` на сервере как
  `RUSTORE_KEY_ID` и `RUSTORE_PRIVATE_KEY`.

Серверные push-уведомления (Монетизация → Уведомления на сервер) пока НЕ нужны —
сервер сам спрашивает RuStore о статусе покупки при каждом `/api/rustore/grant`,
без ожидания уведомлений. Можно будет добавить позже.

### 5. Запустить сборку
**Actions → Build signed AAB for RuStore → Run workflow** (или просто запушить
изменения в ветку `master`). Через несколько минут скачать артефакт
`mani-magic-rustore-aab` — это файл для загрузки в консоль RuStore.

### 6. Загрузить в RuStore и пройти модерацию
В консоли RuStore → загрузить `.aab` → отправить на модерацию. По опыту похожих
приложений — будьте готовы к 2-3 попыткам (модератор может попросить убрать
следы «браузерности» — стандартный процесс, не повод для паники).

### 7. Проверить на реальном устройстве
Здесь нужен ваш телефон — установить тестовую сборку и пройти покупку целиком
(RuStore поддерживает тестовые покупки без реальных денег до публикации).

## Локальная разработка (без сборки)

```bash
node sync-www.js      # обновить www/ из ../app
npx cap sync android   # синхронизировать с нативным проектом
```

Собрать `.aab`/`.apk` локально без Android Studio нельзя — для этого и
существует `build-rustore.yml`.
