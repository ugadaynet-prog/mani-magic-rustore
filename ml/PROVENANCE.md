# Происхождение обучающих данных модели сегментации ногтей

Документ отвечает на вопрос, который при продаже приложения задают первым:
на чём обучена модель и вправе ли мы это использовать. Проверено 1 сентября
2026 года через GitHub API (`gh api repos/OWNER/NAME --jq .license.spdx_id`).

## Что используется сейчас

| источник | кадров | лицензия | основание |
|---|---|---|---|
| [vpapenko/nails-segmentation-dataset](https://github.com/vpapenko/nails-segmentation-dataset) | 52 | **CC0-1.0** | отказ от прав, коммерческое использование разрешено без условий |
| Колода MANI Magic (`app/assets/works`) | 245 | наша | изображения сгенерированы нами, права наши |
| Ручная разметка, части «студия» и второй круг | 49 | наша | те же наши изображения, обведены руками |

Маски для колоды сделаны `label_deck.py` без ручной разметки:

1. **MediaPipe Hand Landmarker** (Google, **Apache-2.0**) находит кисть и
   суставы пальцев.
2. По кончику пальца и суставу DIP считается, где лежит ногтевая пластина.
3. **MobileSAM** (**Apache-2.0**, на базе Segment Anything от Meta, тоже
   Apache-2.0) по точке и рамке обводит контур ногтя.

Обе лицензии разрешают коммерческое использование. Ни один шаг не опирается
на данные без лицензии.

Тёмный и чёрный маникюр досоздаётся из уже готовых масок перекраской внутри
контура (`synth.py`): исходные наборы почти не содержат тёмного лака, и
модель на нём слепа. Новых изображений извне это не привлекает.

Энкодер — MobileNetV3-Small с весами `IMAGENET1K_V1` из torchvision
(BSD-3-Clause). Общепринятая практика для коммерческих продуктов.

## Что исключено и почему

Эти пять наборов участвовали в обучении до 1 сентября 2026 года и
**исключены**: на GitHub у них нет файла лицензии, то есть автор не давал
никаких прав. Отсутствие лицензии — это не разрешение по умолчанию.

| источник | кадров | лицензия |
|---|---|---|
| PaulinaPacyna/image-processing--nails-segmentation | 53 | нет |
| Zea-Zee/nails-semantic-segmentation-pytorch | ~235 | нет |
| behroozmrd47/Spatial_RNN_Fingernail | 266 | нет |
| Golbstein/Fingernails-Segmentation | 193 | нет |
| ademakdogan/nails_segmentation | 52 | нет |

Прав тут два слоя: автор набора владеет разметкой и составлением коллекции,
а фотографии в таких наборах часто собраны из интернета, то есть их автор мог
и сам не иметь права ими делиться. По репозиторию без лицензии это не
проверить в принципе.

Скрипт `prepare_dataset.py`, который их скачивает, оставлен в истории только
как след; в обучении он больше не участвует. Веса, полученные на этих данных
(`best-v3.pt`, `checkpoint-v3.pt`, `nail-unet-v3.onnx` в релизе `try-on-v2` и
`app-addons/tryon/nail-unet.onnx` в репозитории), считаются грязными и
подлежат замене.

## Почему не взяли другие готовые наборы

Искали 1 сентября 2026 года: Hugging Face (полный каталог по четырём
запросам), Zenodo, GitHub (31 репозиторий по всем формулировкам). Наборов
масок ногтей со свободной лицензией не нашлось: лицензия есть только у
vpapenko. Openverse отдаёт снимки под CC0, но без масок и с низкой
релевантностью. Вывод: готового большого набора со свободной лицензией в
открытом доступе нет, поэтому собственная колода и есть основной ресурс.

## Контрольные фото

Папка `тест-распознавания` (23 снимка по цветам лака) собиралась как набор
только для замера: снимки взяты из открытых источников (Pinterest и подобные),
в приложение и в репозиторий не попадают и никуда не передаются.

С 6 по 8 сентября 2026 года это было не так. Когда появилась ручная разметка,
22 из этих снимков попали в эталон `labels`, а `prepare_gold.py` раскладывает
эталон на обучение и экзамен — 15 контрольных кадров оказались в дообучении.
Модель на них не только проверялась, но и училась.

**С 8 сентября 2026 года часть «контроль» из обучения исключена**
(`finetune.py`, по умолчанию; вернуть можно ключом `--with-control`, он
оставлен только чтобы повторить старый замер). Сборка, которая идёт в
приложение, обучена без единого чужого снимка: CC0-набор vpapenko, наша колода
и наши же кадры ручной разметки. Контрольные снимки остались в экзамене —
измерять чужой фотографией можно, выводить из неё модель незачем.

Цена известна и записана в README: удаление пятнадцати кадров стоило трёх
ногтей из 81 на отложенных, два из них вернула аугментация наездом камеры.

Решение владельца от 8 сентября 2026 года по самим снимкам: «Только эти фотки
из пинтерест, мы их можем использовать» — записано, чтобы потом не гадать,
откуда взялись эти кадры и кто их одобрил.

## Ногти без лака (`labels3`)

14 снимков принёс владелец 8 сентября 2026 года — оттуда же, из Pinterest и
похожих подборок. Набор **только для замера**: в обучение он не идёт ни целиком,
ни частью, поэтому по правам это тот же случай, что и `тест-распознавания` до
6 сентября.

Три файла с водяными знаками стоковых банков (`stock-photo-…`, `kisspng-…`,
`very-well-cared-…`) отложены в `ногти-без-лака/со-стоков-не-брать` и в задание
не попали. Ещё один кадр убран уже после разметки: в углу нашлась подпись
автора — такие снимки не берём даже на замер, чтобы не разбираться потом,
чья это подпись.

Осталось 13 кадров, 59 ногтей, обведены руками (`ml/labels3`).

## Как проверить самому

```bash
gh api repos/vpapenko/nails-segmentation-dataset --jq .license.spdx_id
```

Список кадров с указанием источника для каждого пишется при сборке в
`dataset_merged/manifest.json` и кладётся в релиз как
`dataset-manifest-clean.json`.
