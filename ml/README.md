# Сегментация ногтей для примерки цвета

Обучение маленькой модели, которая по фото руки выдаёт маску ногтей. Маска
нужна примерке цвета (`tryon/` в основном проекте): найти ногти и перекрасить,
сохранив блики и тени.

Лежит здесь, а не рядом с веб-приложением, потому что `app/` целиком уезжает
внутрь Android-сборки (см. `sync-www.js`), и данные с обучением попали бы в APK.
В сборку из этого репозитория идёт только `www/`, каталог `ml/` в неё не входит.

## Почему вообще модель

Три эвристики на пикселях провалились, все по одной причине:

1. **Овал от точек кисти.** MediaPipe ставит точку «кончик пальца» там, где по
   её представлению кончается ПАЛЕЦ. Модель обучена на обычных руках, длинного
   нарощенного ногтя не знает и считает его фоном — точка приходится на
   основание ногтя, овал промахивается на две трети длины.
2. **Выращивание области по цвету от семени.** Семя часто садится на кожу, кожа
   однородная, краска расползается кляксами по пальцу. Выглядит хуже овала.
3. **Отсев областей цвета кожи.** Кляксы почти ушли, но покрытие упало вдвое.

## Данные

`data/nails.zip` — [vpapenko/nails-segmentation-dataset](https://github.com/vpapenko/nails-segmentation-dataset),
**лицензия CC0-1.0** (общественное достояние, коммерческое использование без
ограничений). 52 пары «фото + маска», размеры разные, ногти занимают ~3.6%
кадра. Маски сохранены в JPG, поэтому значения размыты сжатием и бинаризуются
порогом.

Другие найденные наборы (`behroozmrd47/Spatial_RNN_Fingernail`,
`Golbstein/Fingernails-Segmentation`) **без лицензии** — брать нельзя.

52 картинки — мало. Этого хватает, чтобы собрать и проверить весь конвейер
целиком (обучение → ONNX → браузер) прежде чем вкладываться в разметку своих
фото. Расширение набора — следующий шаг.

## Как запустить

Локальная машина не тянет (8 ГБ памяти, свободно меньше гигабайта), боевая ВМ
тем более (2 ГБ, и на ней живёт API). Считаем в GitHub Actions: вручную,
`Actions → Train nail segmentation → Run workflow`. Результат — артефакт
`nail-model` с `nail-unet.onnx` и `metrics.json`.

```
python ml/prepare.py     # zip → 256×256, бинарные маски, prepared.npz
python ml/train.py       # U-Net с энкодером MobileNetV3-Small
python ml/export.py      # → ONNX для onnxruntime-web
```
